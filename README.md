# Module 07b Lecture Activity

STEP 1: TEAM & RESPOSITORY SETUP
- Form team of 5 students.
- Team Lead creates public repo with README.md.
- Team Lead invites 4 team members under Settings > Collaborators.
- Team Lead enables GitHub Pages (Settings > Pages > Branch: main).
- Team Members accept collaboration email invite.

STEP 2: CLONE & CREATE FILE
- Clone the team repository to your local machine.
- Create `<your-netid>.md` (e.g., `jsmith2.md`).
- Add Name, Major, Favorite CS Topic, and Challenging Topic.

STEP 3: GIT WORKFLOW
- LOCAL COMMIT: Save local snapshot with message.
- PULL: Retrieve latest commits from teammates.
- PUSH: Upload local commits to remote GitHub repository.

STEP 4: INDEX & VERIFY PAGES
- Add links for all `<netid>.md` files inside `README.md`.
- Visit live GitHub Pages URL and test all 5 student links.

STEP 5: PEER REVIEW & ENHANCEMENT
- Review teammate's file on GitHub.com and leave feedback.
- Add table.image.code block to your `.md` file, then Commit-Pull-Push.
